# 🚦 Traffic Detection using YOLOv8

A deep learning-based traffic monitoring system built using **Ultralytics YOLOv8**, designed to detect and analyze vehicles in real-time traffic scenarios, with a focus on Indian road conditions.

---

## 🚀 Features

* 🚗 Real-time vehicle detection
* 🧠 Powered by YOLOv8 (Ultralytics)
* 📊 Works on custom traffic datasets
* ⚡ Lightweight model (YOLOv8n) for fast inference
* 🎥 Video input support

---

## 🧠 Model Details

* Model: **YOLOv8n (Nano)**
* Framework: Ultralytics YOLOv8
* Language: Python
* Backend: PyTorch
